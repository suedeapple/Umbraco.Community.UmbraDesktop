# Media Info

Media Info shows everything about one file in the media library, the way a file's Properties did in
Windows. To look at a file, select **Open…** and choose it in Umbraco's media picker.

Each group appears only when the file has something for it:

- **File**: its name, file name, media type, format, size, when it was created and last changed, and
  where it is on the site.
- **Picture**: its dimensions, and its focal point if one was set in the Media section.
- **Sound and video**: its length, and a video's dimensions.
- **Camera**: for a JPEG photo, the camera, when it was taken, the exposure, aperture, ISO and focal
  length, as the camera wrote them.
- **Place**: where a photo was taken, if the camera or phone recorded it. Select **Show on a map** to
  open the place on OpenStreetMap in a new tab.

To copy every fact as text, for a support request or a ticket, select **Copy**.

A photo that records where it was taken tells anyone who downloads it from the site. Media Info is a
quick way to check before you use a photo on a public page.
