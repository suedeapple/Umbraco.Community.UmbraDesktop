# Sound Recorder

Sound Recorder records a short clip from your microphone, such as a voice-over or a spoken
introduction, and keeps it for you as a file.

To record:

1. Select **Record**. The first time, the browser asks whether the site may use the microphone.
   Allow it.
2. Speak. The trace shows the sound as it is recorded, and the counter how long it is.
3. Select **Stop**. The recording is named for when it was made.

A recording can be up to ten minutes long, and stops by itself at that point.

To keep the recording, change its name if you want to, then:

- To save it on your computer, select **Download**.
- To add it to the media library, select **Add to Media**, choose a folder, and select **Choose**.
  It becomes a media item with the recording's name.

To hear it first, select **Play**.

Until a recording is downloaded or added to the media library, the window shows the unsaved dot, and
closing it, or selecting **Record** again, asks first.

## When recording does not start

The message in the window says which of these it is:

- The microphone was not allowed. Allow it for the site in the browser's address bar, then select
  **Record** again.
- No microphone was found. Connect one and try again.
- The backoffice is not on HTTPS. Browsers only allow recording on a secure address, or on
  `localhost`.
- The microphone is in use by another program. Close that program and try again.

Recording happens in your browser, and nothing is sent anywhere until you select **Add to Media**.
