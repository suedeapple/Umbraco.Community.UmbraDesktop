# CD Player

CD Player plays a media folder of sound files the way a CD player plays a disc: the folder's sound
files are the tracks, in the order the Media section lists them. Everything else in the folder is
skipped.

To put a disc in, select **Open…** and, in Umbraco's media picker, choose either:

- a folder, to start at its first track. Select the tick in the folder's corner, since selecting the
  folder itself opens it in the picker
- a sound file, to start at that track, with the rest of its folder as the other tracks

Then select **Play**. When a track ends the next one plays, and after the last the disc stops and goes
back to track 1.

- To play a track from the list, select it.
- To go to the next track, select **Next track**, or press the Right arrow. To go back, select
  **Previous track**, or press the Left arrow. A few seconds into a track, **Previous track** starts
  it again instead.
- To play the tracks in a random order, select **Shuffle**. Select it again for the folder's order.
- To repeat, select the repeat button. It goes from **Repeat: off** to **Repeat: all**, which goes
  round the disc, then **Repeat: one**, which plays the same track again, and back.
- To pause, select **Pause**, or press Space. To go back to the start of the track, select **Stop**.

CD Player has its own column in [Volume Control](volume-control.md). Closing the window stops it.
