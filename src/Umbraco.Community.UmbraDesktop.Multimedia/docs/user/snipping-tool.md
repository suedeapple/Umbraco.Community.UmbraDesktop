# Snipping Tool

Snipping Tool takes screenshots and screen recordings: of a whole screen, one window or one browser
tab. The browser asks you which, every time, in its own picker. A web page cannot see your screen any
other way.

- To take a screenshot, select **New screenshot**, then choose what to capture in the browser's
  picker. The browser stops sharing as soon as the screenshot is taken.
- To record, select **Record screen**, choose what to record, and select **Stop** when you are done.
  Selecting **Stop sharing** in the browser's own bar stops the recording too. A recording can be up
  to ten minutes long.

Closing the browser's picker without choosing anything does nothing.

To keep the capture, change its name if you want to, then select **Download** to save it on your
computer, or **Add to Media**, a folder and **Choose** to add it to the media library. Screenshots are
saved as PNG, so text in them stays sharp, and recordings as WebM. To play a recording back first,
select **Play**. It plays through the Snipping Tool column in [Volume Control](volume-control.md).

Until a capture is kept, the window shows the unsaved dot, and closing it or capturing again asks
first.

A whole screen includes the desktop and everything on it. For a tidier capture, share a single window
or tab.
